## 這批素材對既有待確認題的影響（給 /req-intake 回填用，本 skill 不做分析）
- **Q-29 已結案（PM 2026-11-18）**：家畜健康聲明書、化製原料來源單**都來自防檢署屠宰衛生檢查資訊系統**；規格書寫「證明書」，與 1020 的「聲明書」是同一份東西，**名稱以「家畜健康聲明書」為準**。
- **Q-14 有答案**：家畜健康證明書 API 有 `serialNo` 流水號（唯一值）；匯出也有流水號且無重複。
- **Q-17 有答案**：疫情通報 API 有送檢動物名稱與數量（Anil／Num）、疾病名稱（DiseaseName）、確診名稱（DiseaseNameConfirm）、判定日期；沒有「判定結果＝確診」這種欄位，也沒有發病頭數。
- **Q-13 已改變（PM 2026-11-18）**：這些 API 由 NCDR 寫進資料庫，**我方只讀資料庫，不直接呼叫 API**；D-1、365 天等 API 限制是 NCDR 的事。我方還需知道的只剩資料庫更新頻率與歷史保留範圍（問 NCDR，簡報已有「相關資料中心是否會協助資料庫」）。
- **Q-09 有答案**：經緯度來自牧場資訊管理系統 API（lat／lon）；疫情通報 API 也有 lat／lon 但可為 null（範例為 0）。
- **Q-02 出現新風險**：疫情通報 API 的防疫統編欄位型態為 nchar(10)，且**允許 null**（範例即為 null）。統編為空時無法對回畜牧場。
- **欄位差異**：疫情通報 API 欄位表沒有案號 `CaseID`（範例有）、沒有判定結果文字；化製原料來源單 API 沒有秤重日期、淨重；牧場 API 只有場址（無縣市、鄉鎮、村里分欄），縣市鄉鎮需從地址或登記系統取。
- **Q-28 仍待答**：登記系統 33,378 場（全畜種）；屠宰端有 5,388 場、化製端 4,962 個統編；牧場資訊管理（新）沒有全量樣本，無法比對母體。
- **防疫統編 ABCD 意義**：A＝持畜牧場登記證（A＋證號後 5 碼）、B＝持畜禽飼養場登記證（B＋證號後 5 碼，證號 8 碼）；C、D＝沒有登記證號（登記證欄全為空），查不到官方 C／D 的定義（見 [[儀表板設計決議]] 11/18 紀錄）。登記系統 A 23,855、B 1,395、C 227、D 7,901。
