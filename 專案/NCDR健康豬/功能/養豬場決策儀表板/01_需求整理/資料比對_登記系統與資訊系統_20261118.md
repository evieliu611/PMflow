# 登記系統與牧場資訊管理系統（資訊系統）資料比對
> 整理日期：2026-11-18｜資料基準：畜牧場登記全量 1151105、家畜健康聲明書近一年 1151110、化製原料來源單全量 1151110、動物防疫資訊網地理資訊清單 1150901（3 場）、用藥監測畜牧場列表 1150901（3 場）、NCDR 資料介接說明書
> **限制**：我們沒有「牧場資訊管理系統（新）」的全量資料，只有 3 場示範資料與介接說明書的欄位定義。下面第二至四節的結論，凡標「僅 3 場」的都不能代表全部。要完整比對，需要 NCDR 資料庫裡該系統的實際資料。

## 一、兩邊牧場「對不對得起來」（用屠宰端、化製端的牧場名單當第三方檢查）
| 檢查 | 結果 |
|---|---|
| 登記系統總場數 | 33,378 場（含雞鴨羊牛），豬 11,565 場 |
| 家畜健康聲明書（近一年）出現的牧場 | 5,387 個防疫統編，其中 5,351 個（99.3%）在登記系統，**36 個查無登記**（B 開頭 35、D 開頭 1） |
| 化製原料來源單出現的牧場 | 4,920 個統編，其中 4,904 個在登記系統，**16 個查無登記**（全為 B 開頭） |
| 登記系統內的豬場 | 11,565 場，近一年有送屠宰紀錄的 4,321 場，**7,244 場沒有屠宰紀錄**（可能停養、未出貨或登記資料過時） |
| 同一統編的牧場名稱（登記 vs 屠宰端） | 完全一致 5,328／5,351；差異多為「（廚餘養豬）」後綴、分場與總場、異體字（富釆／富采、龍穎／龍頴），少數為不同牧場名 |
| 同一統編的牧場名稱（登記 vs 化製端） | 完全一致 4,897／4,904 |

**結論**：以登記為母體時，屠宰與化製端有約 0.3%～0.7% 的牧場查不到登記資料，B 開頭最多，雛型的「查無登記」警示有實際用處。登記系統內約六成豬場近一年沒有屠宰紀錄，若以登記為母體，清單會有很多「沒有資料的場」。資訊系統的牧場數目前**無法比對**（無全量資料）。

## 二、場址、標準地籍址是否不一樣（登記 vs 資訊系統）
| 項目 | 登記系統（全量） | 資訊系統（僅 3 場，加介接說明書） |
|---|---|---|
| 牧場場址的內容 | 全部 33,378 場裡：地號 26,378（79%）、門牌 4,849、空白 1,594、其他 557。豬場 11,565 場裡：地號 9,705（84%）、門牌 1,371、空白 400 | 介接說明書的「場址」`ranchAddress` 範例為完整門牌地址（「屏東縣屏東市長安里長安路19號」） |
| 標準地籍址 | 豬場空白 1,068 場；有值時多為場址地號的標準化寫法（例：場址「粗坑段1063、1060地號」→「宜蘭縣員山鄉粗坑段1060、1063地號」） | 介接欄位沒有標準地籍址 |
| 3 場示範比對 | A07221、A08826、A18038 的登記場址**都是地號**（如「日新段6-555地號」） | 地理資訊清單的牧場住址**都是門牌**（如「宜蘭縣員山鄉中華村冷水路33號」） |

**結論**：兩邊的「場址」**不是同一種東西**。登記系統的場址大多是地號、資訊系統是門牌。因此先前「場址＝門牌、標準地籍址＝地號」的假設並不成立：登記系統的場址欄大多本身就是地號，標準地籍址是它的標準化寫法。畫面的「地址」欄應優先取資訊系統的場址（門牌），登記系統的場址與標準地籍址當地籍補充；資訊系統沒資料時才用登記系統。這點建議進簡報 P.9 的問題。

另外，3 場示範裡有村里用字不一致：洽興畜牧場的資訊系統地址是「大村里」，用藥監測和登記是「大里里」。

## 三、登記飼養畜禽種類及數量、設施、牧場種類、在養頭數
| 項目 | 登記系統 | 資訊系統 | 能不能對 |
|---|---|---|---|
| 畜禽種類及數量 | 自由文字，格式例「種公豬(8),種母豬(160),肉豬(462)」；豬場 11,565 場中有數字的 10,200 場、只寫「豬」沒有數字的 1,365 場；混養（豬加羊等）275 場 | 沒有這欄；只有 `animalKind`（牧場種類）與 `animalAmount`（飼養頭數） | **不是同一個意思**：登記是登記時的分類數量，資訊系統是飼養頭數。我們只要豬，需要解析「種公豬＋種母豬＋肉豬＋豬」並加總 |
| 登記頭數規模 | 有數字的豬場加總中位數 810 頭，前 10% 超過 2,025 頭，最大 63,319 頭 | — | 資訊系統無全量，無法比 |
| 在養頭數 | 沒有 | `animalAmount` | 資訊系統無資料，無法比 |
| 主要畜牧設施 | 豬場 11,565 場中空白 1,429 場；有值為自由文字 | 沒有這欄 | 只有登記系統 |
| 牧場種類 | 沒有，只有登記飼養種類 | `animalKind`（豬場、牛場、羊場、家禽場…） | 3 場示範皆為「豬場」，一致 |

**結論**：兩邊在這幾個欄位上是**互補而非重疊**，不是「差不多的內容」，所以不存在「對得起來」的問題，而是需要決定各自負責哪一塊。登記系統的豬數要自己解析，在養頭數只能靠資訊系統，且目前沒有資料可驗證。
