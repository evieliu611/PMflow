## 一、要請老師拍板的（提問）

### ⭐ Q-01　估算結果的顯示精度
- **雛型現況**：面積顯示到**小數點後 2 位**（例：10.00 km²）、人數**四捨五入至整數**（例：4,500 人）、密度為整數（例：450 人/km²）。
- **為什麼問**：這是老師先前在「人口密度分析規劃畫面」自己列的待確認事項。
- **請老師選**：
  - （A）就照現況：面積 2 位小數、人數與密度取整數。
  - （B）面積要更多／更少位數（請指定幾位）。
  - （C）人數也要顯示到小數（例如攤分後的估計值不取整）。
- **影響**：只動數值呈現格式，不影響版面與計算邏輯。

## 二、順便展示、確認方向（不必逐題發問，老師有意見再記）

這些內部已收斂，投影時走一遍即可；老師若當場有不同意見，就記下來當回饋回填。

| 項目 | 雛型現況（請老師看畫面確認方向） |
|---|---|
| 框選方式 | 在地圖上以**任意多邊形**框選範圍（可貼合行政區、河岸等不規則邊界） |
| 計算內容 | 自動算出範圍內**人數**、**面積(km²)**、**密度(人/km²)** 三項 |
| 人數怎麼算 | 以 100m 人口網格為底，**網格中心點落入框選範圍即計入**加總 |
| 成果清單 | 每框選一次**新增一筆**到清單（不覆蓋前一次），可多筆並列比較 |
| 點選連動 | 點清單某一筆，地圖上對應範圍**高亮**，看得出是哪一塊 |
| 顯示／隱藏、刪除 | 每筆可在地圖上開關顯示；可刪除（刪除會**跳二次確認**防誤刪） |
| 隨專案存檔 | 估算成果**跟著專案存檔**，重開專案還在 |
| 使用時機 | 演練前、演練中都能框選估算 |
| 誰能用 | 情境設定員／系統管理者可框選；**演練人員僅檢視**已存成果 |
| 演練完成後 | 專案「演練完成」後估算工具**唯讀**（只看已存成果、不能再框選） |
| 無人口範圍 | 框到山區、海域等無人口網格的範圍，人數顯示 **0**，仍正常存一筆 |
