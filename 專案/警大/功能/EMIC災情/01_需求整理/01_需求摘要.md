## 一、背景與目標

中央警察大學防災所要用「智慧災害模擬演練平台」做災害應變教學演練。EMIC 災情整合模組讓一場演練能自動帶入消防署 EMIC（應變管理資訊系統）**演練區**的真實災情任務，在地圖上以圖徵呈現各災情點位與其處理狀態，並用時間播放器回放整場演練期間災情處理狀態的時序變化，作為教學與檢討的素材。

## 二、現況與痛點

- EMIC **無處理歷程 API**，單次查詢只能拿到「當下狀態快照」；也**無正式介接機制**，消防署僅提供演練區災情 API 供本案使用（見 memory/外部系統介接方式_TERIA_EMIC.md）。
- 因此「災情處理狀態的時序變化」無法直接向 EMIC 索取，必須由本系統在演練期間**自行累積**才看得到演變 —— 這是本模組設計的核心限制。
- 規劃畫面（參考截圖/現有規劃_EMIC回報模組.png）已定調：演練前先設定、開始演練後自動帶入、演練中/後可透過時間軸播放器檢視。

## 五、非功能需求

- **資料源限制**：EMIC 演練區 API 為「警大_瑞竣」雙方協議專用介接，非公開 API；單次查詢上限 100 筆。
- **儲存效能**：不逐次存全快照，僅記狀態變更時間戳，以控制儲存空間（F-03 的設計動機）。
- **相容既有系統**：本模組是既有前台平台的「EMIC」右側頁籤，風格、專案儲存機制、角色權限沿用既有系統（Mapbox 圖台、專案 3 狀態）。

## 七、範圍界定

- **本次包含（雛型 v2 已納入）**：地圖點位 + 14 類圖徵四狀態色、時間播放器（狀態變更時序回放）、災情清單 + 篩選 + 點位開關/刪除、點選點位看詳情 + 附件。
- **明確不包含**：EMIC 以外的災害情境來源（TERIA 地震情境、線上製圖為其他模組）；EMIC 資料的後台管理（EMIC 屬演練即時取用，非後台上架）。
- **超出合約需追加報價**：無（本模組屬合約六大工作項目①，合約內）。
