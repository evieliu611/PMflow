# 系統概述與功能模組 — 智慧災害模擬演練平台

來源：招標規範/需求說明書（`_共用素材/需求摘要/招標規範_...odt`，全文 MD 在 `轉檔MD/`）。索引見 [[素材清冊]]，合約條款見 [[合約範圍與金額]]。

## 一句話
中央警察大學防災研究所要的**災害模擬演練 Web 平台**：以 GIS 圖台（2D/3D 可切換、向量電子地圖、https）做災害情境的空間化即時呈現，供教學與應變演練使用。

## 功能模組（未來 `功能/` 資料夾大致依此切）
**前台 — 災害模擬演練展示平台**
- 網頁底層／地圖圖台核心：Web（Edge/Chrome）、2D/3D 切換、向量電子地圖、https；底圖至少含國土測繪中心通用電子地圖／正射影像／行政分區，另需提供全台向量圖磚 .PBF。
- 三維防災應變展示介面：災害情境設定模組，線上編輯演練內容、支援匯入匯出。
- GIS 核心：動態渲染、數據可視化、圖層與底圖、比例尺切換、平移、依屬性呈現差異、3D 物件透明度；篩選定位至少 3 種（行政區／地址／座標）；線上製圖（點線面、存成可開關圖層）。
- 演練資訊序列展示模組：圖資時間軸，可設定時間、參與人員、顯示資料。
- 智慧空間解析繪製模組（AI）：由一段文本（災情描述）自動生成災害地圖、時間回溯、套疊圖層、產出並可點選空間資訊定位。
- EMIC 回報資訊整合模組：介接內政部消防署 EMIC（由本校向消防署申請開通）。

**後台管理**
- 帳號申請審核：自建帳號**介接「我的 e 政府」API**，管理者後台審核、可啟用/停用、定期提供活用帳號名單。
- 帳號群組權限管理：依單位／行政區／職位分群，設各群可操作功能。
- 圖層管理：上架自有圖層（**KML／Shapefile／CSV** 三格式）、填詮釋資料、綁瀏覽權限、設圖徵樣式顏色。

**圖資蒐整及處理**
- 公開資料介接：國土測繪中心地籍圖、NCDR 地震衝擊資訊平台（TERIA）、消防署 EMIC。
- 人口密度分析：用土地利用圖資算全台人口密度網格（計算邏輯由本校提供），一次性。
- 資料購買及處理：協助購買全台國土利用調查＋建物框圖資並預處理。
- 資料蒐集：災害／環境／民生三面向彙整圖資數據服務**至少 15 項**。

**非功能／環境**
- 資安：交付前網站弱掃無中高風險；資安等級【普】；CNS 27001。
- 主機採購與架設：正式環境＋測試環境各 1 台，Windows Server 2022+／IIS 8+／MSSQL 2022+，4 核 16G，C:100G/D:500G；含備援與 2 年維護。

## 交付階段對應（PM 排功能優先序參考，日期為 2026 年）
- **第一階段（決標後 20 日曆天內）**：災害模擬演練展示平台**雛型網頁** ← PM 主線雛型直接餵這關。
- 第二階段（09-20 前）：網頁底層架構、三維防災應變展示介面、演練資訊序列展示、資料購買及處理、公開資料服務介接。
- 第三階段（10-10 前）：智慧空間解析繪製、EMIC 整合、後台管理、資料蒐集、系統主機採購及環境架設。
- 結案（10-31 前）：人口密度分析、資訊安全檢測。
