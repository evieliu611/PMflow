業務規則

  • BR-01（F-02）演練開始後，系統每 10 分鐘呼叫一次 EMIC 演練區 API 取災情與狀態；警大防災所已接受此頻率造成的時間差／歷程缺失（memory 定案）。
  • BR-02（F-03）EMIC 無處理歷程 API，不逐次儲存全快照；每次取回時比對，只有案件狀態有變更時，才在對應狀態欄位記下該變更的時間點（節省儲存空間）。
  • BR-03（F-05）播放器在時間點 T 的呈現：取每案件狀態變更時間戳中「時間 ≤ T 的最後一筆」作為該點位當下狀態顏色；案件發生時間 > T 者視為「尚未發生」不顯示。
  • BR-04（F-04）圖徵＝14 類災情各一 ICON × 4 狀態色，與線上製圖模組共用同一套圖徵（memory 定案；圖徵原稿見參考截圖）。
  • BR-05（F-06）篩選：災情類別可複選、縣市、災情狀態可複選；篩選同時作用於地圖點位與清單。
  • BR-06（F-07）點位眼睛＝地圖顯示/隱藏；開關狀態隨專案儲存，重開專案沿用。隱藏≠刪除，資料仍在專案內。
  • BR-07（F-08）刪除＝二次確認後永久移除該災情；被刪除的災情不會出現在專案、也不會被儲存（與眼睛隱藏的差別）。
  • BR-08（F-10）演練日期只能為當天；若當天 23:59 使用者尚未按「結束演練」，系統自動視同結束演練：停止呼叫新災情、專案轉「演練完成」並凍結。
  • BR-09（F-11）演練期間取得的災情、狀態變更時間戳、點位眼睛開關狀態，皆隨專案儲存；專案「演練完成」後不可編輯，僅能「另存」複製（沿用既有系統專案 3 狀態機制）。
  • BR-10（F-02）查詢範圍為全國、系統自動分批取完（單次 API 上限 100 筆）；分批機制與效能 ⚠️ 待技術確認（Q-01）。
