# 人口密度分析計算邏輯

計算邏輯由警大防災所提供，屬**既定業務規則**，PM/PG 不應自行調整分類或權重。

- **資料來源**：①本案採購之國土利用調查成果 ②社會經濟資料服務平台之村里人口資料（採用114年12月版本）。
- **篩選的土地利用分類**：純住宅（050200）、混合使用住宅－兼工業使用住宅（050301）、兼商業使用住宅（050302）、兼其他使用住宅（050303）。
- **計算方式**：以村里為單位，抓行政區內上述4種土地利用分級，**以面積搭配加權攤分村里人口**。加權方式：**兼商業使用住宅權重為「兼其他使用」的2倍**。
- **輸出**：計算結果轉換為網格。**【8/20客戶訪談定案】網格改 50m（先試跑，若效能不行再改回 100m）**；原規劃為 100m。
- **本功能一分為二（8/20客戶訪談定案）**：
  - **工具「人口估算」**：右側面板框選估算，使用者框選範圍後自動加總。**只算人數＋面積(km²)，不再算密度**（客戶確認移除密度）。加總邏輯：網格中心點落入框選範圍即計入。
  - **圖層「建物人口概況」**：納入圖層清單的系統圖層，呈現計算流程中的「村里內各住宅用地人口」，需**分層設色**。級距與色碼（客戶提供，黃→紅）：0～200 `#FFFF00`／200～500 `#F5B800`／500～1000 `#F57A00`／1000～5000 `#F50000`／5000以上 `#980A0A`。**圖層本次不另寫需求文件**（PM 指示聚焦工具），級距色碼先記於此備用。
- **計算流程圖（10 步）**：客戶 8/20 提供的 pipeline 圖 —— 讀單一圖幅(119/121分帶,5,691筆)→篩4類住宅→重投影EPSG:3826→合併圖幅→修復幾何→與村里交集→加權(兼商業x2)攤分村里人口→轉網格→網格與人口圖層交集→網格攤分人口→移除0網格。工具與圖層共用此 pipeline。
- **顯示精度（8/24客戶確認定案）**：面積顯示到小數點後 2 位、人數四捨五入至整數。（密度精度問題因移除密度而消解）
- **角色權限（8/24 PM 確認）**：維護助手權限＝系統管理者。人口估算工具可框選估算者＝情境設定員／維護助手／系統管理者；演練人員僅檢視。
- **合約時程**：人口密度分析屬第三/結案階段（115/10/31前）的交付項目，由廠商於專案至保固期間**一次性**協助計算並匯出圖台可用格式（見 [[合約範圍與金額]]）。
