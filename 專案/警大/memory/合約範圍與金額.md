# 合約範圍與金額

案號 115GA7036，中央警察大學「115年智慧災害模擬演練平台系統採購案」。詳見 [[素材清冊]] 的合約類素材。

- **契約總金額**：新臺幣 10,892,820 元整，**總包價法、固定價格給付**。訂約後系統功能數調整達 5% 以上，或人力投入變動 5% 以上才可調整價金；未達 5% 一律不調整。
- **未列入標價清單但屬「為廠商完成履約所必須」之項目（即原需求規格所列及系統訪談分析已確定之功能）仍須廠商自行負責供應，不得請求加價** —— 這是判斷客戶追加需求是否「⚠️模糊」的關鍵條款：只要能歸類到招標規範六大工作項目或訪談已確認的功能範圍內，即使標價清單沒有列，也算合約內。
- **履約期限**：決標次日起至 115/10/31。分期付款：第二期款(50%)於期中審查通過後撥付，第二期款(50%)於結案驗收通過後撥付。保固2年，保固金為契約總價3%。
- **六大工作項目**（超出這六項才明確算 ❌ 超出範圍）：①災害模擬演練展示平台 ②後台管理 ③圖資蒐整處理 ④系統資訊安全檢測 ⑤專案團隊組成 ⑥系統主機採購及環境架設。
- **分階段交付期程**（詳見招標規範）：決標+20天雛型網頁 → 115/9/20第二階段（網頁底層架構/三維防災害應變展示介面/演練資訊序列展示模組/資料購買及處理/公開資料服務介接）→ 115/10/10第三階段（智慧空間解析繪製模組/EMIC回報資訊整合模組/後台管理/資料蒐集/系統主機採購及環境架設）→ 115/10/31結案（人口密度分析/資訊安全檢測）。**客戶要求提前或延後某功能的階段別，可能牽動查驗與撥款時程，屬於要跟主管確認的範疇，不要自行認定合約內。**
- **8/31校慶展示**是客戶重視的里程碑（非合約正式驗收點），已確認以TERIA地震情境為主體＋3D建物損壞套色＋淹水潛勢等圖層＋地圖繪製工具。
