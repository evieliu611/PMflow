# 技術棧與介接 — 智慧災害模擬演練平台

由 PM 於需求訪談中告知，非合約白紙黑字；後續有主管正式結論再更新。索引見 [[素材清冊]]，功能見 [[系統概述與功能模組]]。

## 已知技術棧
- **地圖核心：Mapbox**（PM 2026-08-14 明確告知「系統是使用 Mapbox 核心」）。
  - 影響：雛型的「接近真實地圖」需求與 Mapbox GL 有關；但**雛型本身不接 live Mapbox**（需 token、需連網、與「離線可開」鐵則衝突），改以向量示意底圖模擬，正式系統才用 Mapbox。
- 主機環境（合約明訂）：Windows Server 2022+／IIS 8+／MSSQL 2022+。→ 後端偏 .NET／IIS 生態。

## 外部介接對象（合約明確，介接方式待技術主管確認）
- **EMIC**（內政部消防署 應變管理資訊系統）：回報災情內容，須由本校向消防署申請開通服務。→ 平台時間軸只綁 EMIC 災情資料。
- **TERIA**（NCDR 國家災害防救科技中心 地震衝擊資訊平台）：地震事件資訊（無時間軸維度，靜態套疊）。
- **國土測繪中心**：地籍圖、通用電子地圖/正射影像底圖；另需全台向量圖磚 .PBF。
- **我的 e 政府**：後台帳號自建介接的 API（屬後台管理功能）。

## 待技術確認（帶畫面找主管談，結論回填此檔）
- ⚠️ 學員端「看到專案最新狀態」的**即時同步程度**（自動推播 vs 重新整理）—— 影響是否需 WebSocket/SignalR。
- ⚠️ EMIC／TERIA 的實際介接方式（API 拉取頻率、認證、資料格式）。
