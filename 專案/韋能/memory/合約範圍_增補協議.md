- 擴充服務總價：項目合計 1,220,000，**折扣專案價 1,200,000（含稅）**。差旅餐費等未經甲方事前書面同意不得另請款。
- 付款：完成 2.4 競合分析並經甲方確認 → 開 530,000 發票；完成全部並確認 → 開 670,000。
- 保固：原＋擴充服務皆自擴充服務驗收完成後起算一年。
- 增補協議與原合約相悖時以增補協議為準。
